# Paradise Nursery Shopping Application

## About the Project
Paradise Nursery is an online plant shopping application designed to help customers explore and purchase beautiful houseplants for their homes.

## Features
- Browse houseplants organized into categories.
- View plant names, images, descriptions, and prices.
- Add plants to a shopping cart.
- Increase or decrease product quantities.
- Remove products from the shopping cart.
- Calculate item totals and the overall cart amount.
- Display a dynamic shopping cart item count.
- Navigate between Home, Plants, and Cart pages.
- Display a checkout message indicating that checkout is coming soon.

## Technologies Used
- React
- JavaScript (JSX)
- CSS
- Redux Toolkit
- React Redux

## Project Structure
- `README.md` — Project documentation
- `AboutUs.jsx` — Company information
- `App.css` — Application styling
- `App.jsx` — Main application and landing page
- `CartSlice.jsx` — Shopping cart state management
- `ProductList.jsx` — Plant listing and product categories
- `CartItem.jsx` — Shopping cart page and item management

## Purpose
This project demonstrates the development of an interactive online shopping experience using React and Redux Toolkit.
